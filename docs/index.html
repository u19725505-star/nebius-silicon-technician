What this does not show

  • The BMC is an emulator that returns standard Redfish-shaped data. No real server was connected.
  • The benchmark comes from our own simulator. Real hardware will be messier.
  • Both large models raised false interrupt-storm alarms on healthy cores in some runs, which is why the guardrails exist.
  • The six scenarios are a behavior demo, not an accuracy test. The accuracy evidence is the scorecard.
  • The processor measurement ran on a 2-core container, not a GPU server. No GPU was used.
  • Actions vary between runs. In this recording the hot-inlet case did not light the LED.
